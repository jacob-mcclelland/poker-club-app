## Quick Summary

**Project**: Tournament Timer Display for All-In Poker Club
**Target**: TV/Projector display at venues (Tight End, Wild Corgi)
**Key Features**:
- Auto-updating leaderboard and bounty displays from Firebase
- Blind timer with 13+ level structure including breaks/chip-ups
- Hand of Night from Google Sheets
- Multi-venue branding support
- Dual-game display (Game 1 large, Game 2 hidden until activated)
